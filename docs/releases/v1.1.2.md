# Alloy-XRD-Bench v1.1.2: correction release

Released 2026-10-09. This is a correction to the v1.1 series, not the planned
v1.2 experimental-validation milestone. The original v1.1 files and split
membership remain unchanged and available.

## What changed

- Corrected SRO zero-count handling: a defined central-species shell with zero
  occurrences of a neighbor species now has alpha=1 for that pair. Undefined
  shells and absent central species remain masked.
- Added a source-bound label overlay covering 88,019 states (84,019 source
  structures and 4,000 fixed-lattice counterfactual states), with 669,370 newly
  defined target entries. Independent coordinate-based checks covered 1,819
  states. These checks establish arithmetic consistency under the declared
  shell convention, not experimental truth or finite-size convergence.
- Published corrected-label HEA result summaries, composition-versus-spectrum
  comparisons, paired-parent intervals, and fixed-cell diagnostics. Parent
  bootstrap intervals condition on the fitted models; they are not physical
  label uncertainty or a replacement for variation across training seeds.
- Corrected Gamma evaluation and public-input handling, and implemented an
  area-normalized perturbation renderer. A complete corrected Gamma result
  matrix and matched evaluation of the new renderer remain outstanding.
- Updated the manuscript, bibliography, corresponding-author information,
  funding acknowledgments, and the requested Table 5 emphasis.

The common long-term objective is alloy powder-XRD refinement. HEA-SRO and
Gamma-Decomp are two complementary subproblems in this first-stage benchmark,
with separate metrics, not a completed joint refinement pipeline.

## Data and compatibility

The correction files are under `corrections/v1.1.2/` in the
[Hugging Face dataset](https://huggingface.co/datasets/jimi7771/alloy-xrd-bench/tree/v1.1.2).
Download that directory or its packaged archive together with the existing
`sitexrd_benchmark_data_v1_1.tar` base archive. Keep `labels.parquet` and
`revision.json` together. Check `SHA256SUMS.txt` before use.

Set `sro_label_revision` in the HEA validation configuration to the local
correction directory. The loader checks the original task-manifest hash, the
overlay hash, target vocabulary, complete ID coverage, and unchanged identity
fields before applying the correction. Do not silently overwrite the original
`manifests/task_samples.parquet` or compare corrected scores to historical
scores as if the target mask were unchanged.

The labels file is keyed by `structure_state_id`, with `parent_group_id`,
`xrd_sample_id`, and `structure_sha256`. It is an all-states label sidecar, not a
new train/test split. Frozen ID, composition OOD, chemistry OOD, and legacy SRO
OOD membership comes from the original task manifest. The legacy SRO OOD split
was defined using the old sparse labels; its membership is retained for paired
comparison, not revalidated as a newly defined label-shift split.

Example, after downloading the base and correction files:

```python
import json
from pathlib import Path
import pandas as pd
from alloy_xrd_bench.sro_revision import apply_label_revision

base = Path("data/benchmarks/siteXRD-bench-v1_1/hea/benchmark_v1")
revision = Path("data/corrections/v1.1.2")
manifest_path = base / "manifests/task_samples.parquet"
metadata = json.loads((revision / "revision.json").read_text())
corrected = apply_label_revision(
    pd.read_parquet(manifest_path), manifest_path, revision,
    metadata["sro_targets"],
)
assert len(corrected) == 88019
```

## Evidence boundaries

Clean simulated spectra show incremental predictive value over composition.
Fixed-cell effects are smaller and the old perturbation renderer confounded
width changes with relative integrated peak areas. Old perturbation results
must not be treated as validation of the replacement renderer or measured noise.

Experimental SRO research exists. The current benchmark does not supply
independently quantified, sample-matched experimental SRO or reflection-level
component targets. Existing measured patterns support phase/whole-pattern
checks. Traditional Rietveld/full-pattern comparisons, privileged-information
baselines, finite-size/configuration-sampling studies, measured-noise
calibration, and diffuse-scattering validation remain open. This correction
does not assert that the complete benchmark-readiness gates now pass.
